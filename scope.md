# Group Web Designing — Project Scope

## Reminder
**Group Web Designing Project Requirements and Timeline**

---

# 1. Grading Format

- **Wireframe** — 15%  
- **30% Progress** — 25%  
- **60% Progress** — 25%  
- **100% Finished** — 35%  

---

# 2. Requirements

## A. Wireframe
- Create **two (2) wireframe sketch designs**
- Submit with **printed documentation**

## B. Implementation Progress
- Submit **30%, 60%, and 100% progress** of web design implementation
- Each stage must include **printed documentation**

## C. Presentation
- Conduct **group presentation**
- Compile and submit all documentation
- Each group must present their outputs

---

# Printed Documentation Must Include

## 1. Process Documentation
- Pictures taken during the development process

## 2. Questionnaires

### A. Contributions
- Explain the specific contributions of each group member
- Provide clear and detailed explanations

### B. Challenges and Positive Gains
- Describe challenges faced individually and as a group
- Explain positive gains individually and as a group
- Provide clear and specific answers

- **30% Progress** — February 19, 2026  
- **60% Progress** — March 5, 2026  
- **100% Finished** — March 19, 2026
